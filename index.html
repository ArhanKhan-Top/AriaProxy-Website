AriaProxy is an experimental Android + Go project exploring Minecraft Bedrock networking, RakNet transport, and NetherNet workflows — with the goal of making the connection experience feel more native and understandable.

01 / Project overview

A networking project, built in the open.

AriaProxy brings together an Android companion experience and a Go-based networking core. The work is focused on understanding and improving the path between Bedrock clients and supported server connection flows.

03 / Core areas

What AriaProxy is exploring.

A practical engineering project, with the networking path and the app experience treated as one system.

Bedrock networking

Research and implementation around RakNet transport, protocol compatibility, and NetherNet connection flows.

Android companion

Account & key safety

04 / Current focus

Make the fundamentals solid.

These are engineering priorities, not claims that every item is already complete.

01

Reliable server joining

Trace the complete connection lifecycle and make failures visible instead of leaving users waiting indefinitely.

02

Honest app state

Keep controls and status indicators connected to real backend capabilities.

03

Local network features

Develop and validate local/LAN workflows as part of the broader connection experience.

04

Safer persistence

Make account and key storage predictable, testable, and transparent to the user.
